## Operating Philosophy

Production reliability comes from safer operational systems, not stronger infrastructure.

Failures usually stem from unclear ownership, unsafe change processes, alerting that doesn't guide action, and poor incident coordination.

**I design systems where the correct operational action is the easiest action.**
